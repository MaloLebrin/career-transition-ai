# 2026-10-04 — Hero : le paysage s'anime

La variante `hero` de `LandscapeArt` s'anime doucement, en CSS pur (aucune dépendance) :
nuages qui dérivent, oiseaux qui traversent, halo du soleil qui respire, reflets du lac qui
ondulent. Classes `landscape-*` dans `inertia/css/app.css`, désactivées par
`prefers-reduced-motion`. Les variantes `dusk` et `horizon` restent immobiles.
